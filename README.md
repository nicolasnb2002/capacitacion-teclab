# Capacitación Teclab · Proceso de venta

Sitio estático de capacitación para asesores comerciales nuevos de Teclab. Explica qué es Teclab y sus diferenciales, cómo usar el Dashboard Comercial para vender, a quién se le vende cada carrera, el proceso de venta paso a paso, el manejo de objeciones, guiones de llamada y de WhatsApp, inscripción y documentación, un checklist para practicar y un quiz.

## Cómo verla

1. `git pull` (o cloná el repo).
2. Abrí `index.html` con doble clic. No necesita servidor ni conexión: el CSS y el JS están dentro del archivo.

## Aviso

**Contenido interno.** No lo publiques ni lo compartas fuera del equipo comercial (nada de GitHub Pages ni de links públicos). No incluye precios, cuotas, tasas ni montos de becas: las promos y la financiación vigentes se consultan siempre en el Portal y el Cotizador. Tampoco incluye credenciales ni datos de prospects o alumnos.
